Pembaruan dari GitHub

Versi baru? Ada tombolnya.

SweepDesk memeriksa rilis baru saat dibuka, paling sering sekali sehari. Jika ada versi baru, tombol Perbarui sekarang muncul di atas daftar aplikasi.

Anda juga bisa memilih Tindakan lainnya → Periksa Pembaruan. Paket diperiksa dengan SHA-256 sebelum dipasang. Pilihan pemeriksaan otomatis ada di Pengaturan → Pembaruan.

Pembaruan langsung tersedia untuk instalasi paket DEB, RPM, dan Arch. Instalasi dari sumber/arsip portabel serta sistem immutable membuka panduan pembaruan manual.

Distro berbeda. Paket berbeda.

Pilih paket yang sesuai.

Ubuntu dan Mint memakai .deb. Fedora dan openSUSE memakai RPM. Arch memakai paket Pacman. Pilih keluarga distro Anda di bawah.

Distro Linux apa saja yang didukung?

Paket sistem didukung pada keluarga Debian/Ubuntu, Fedora/RHEL, openSUSE, Arch, dan Alpine. Mint, Pop!_OS, Zorin, EndeavourOS, Manjaro, dan turunan yang kompatibel memakai keluarga paketnya. Basis yang benar-benar diuji tercantum di README. Sistem immutable seperti Silverblue, Bazzite, MicroOS, dan SteamOS memakai pembaruan sistem bawaan; SweepDesk tidak memaksa mengubah sistemnya.

Apakah semua sisa instalasi pasti terhapus?

Tidak untuk semua pemasang. Pengelola paket mencatat sebagian file; skrip bebas mungkin tidak mencatat perubahannya. SweepDesk hanya membersihkan lokasi yang dikenali. Pembersihan data bersifat pilihan, dependensi bersama disimpan, dan data pengguna yang dikenali masuk ke Sampah.

Apakah perlindungan Python sistem dilewati?

Tidak. SweepDesk mematuhi PEP 668 dan tidak memaksa pip mengubah Python yang dikelola sistem. Tambahkan lingkungan virtual untuk memeriksa dan mengelola paketnya secara terpisah.

Gratis? Apakah daftar aplikasi saya dikirim ke luar?

SweepDesk gratis dan bersumber terbuka. Pemindaian berjalan lokal. Daftar perangkat lunak dan log operasi tidak diunggah. Ekspor daftar ke JSON hanya dilakukan jika Anda memilihnya.
