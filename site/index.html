Updates from GitHub

New release? There’s a button.

SweepDesk checks for a new stable release at startup, at most once per day. When one is available, Update Now appears above your software list.

You can also choose More → Check for Updates. Packages are checked with SHA-256 before installation. Automatic checks can be changed in Settings → Updates.

In-app installation supports DEB, RPM, and Arch package installs. Source/portable installs and immutable systems open the manual update guide.

Good to know

A few honest answers.

Which Linux distributions are supported?

Native package inventory/removal supports Debian/Ubuntu, Fedora/RHEL, openSUSE, Arch, and Alpine families. Compatible derivatives such as Mint, Pop!_OS, Zorin, EndeavourOS, and Manjaro use their parent package family. The README lists tested base images. Immutable desktops such as Silverblue, Bazzite, MicroOS, and SteamOS keep their system updater; SweepDesk does not force changes to their base system.

Will it delete every last leftover?

Not for every installer. Package managers own some files; arbitrary scripts may not record what they changed. SweepDesk only cleans locations it knows. Data cleanup is opt-in, shared dependencies are preserved, and known user data goes to Trash.

Does it override system Python protection?

No. SweepDesk respects PEP 668 and does not force pip to modify an externally managed system Python. Add a virtual environment to inspect and manage its packages separately.

Is it free? Does it send my inventory anywhere?

SweepDesk is free and open source. Scanning runs locally. It does not upload your software inventory or operation logs. Exporting a JSON inventory is your choice.
