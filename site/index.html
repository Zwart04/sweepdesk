Good to know

A few honest answers.

Does it work on Ubuntu and Linux Mint?

Yes, it targets Debian-family desktops, including Ubuntu and compatible derivatives such as Mint, Pop!_OS, LMDE, and Zorin. The required versions and tested base images are listed in the README. Every derivative is not independently tested.

Will it delete every last leftover?

Not for every installer. Package managers own some files; arbitrary scripts may not record what they changed. SweepDesk only cleans locations it knows. Data cleanup is opt-in, shared dependencies are preserved, and known user data goes to Trash.

Does it override system Python protection?

No. SweepDesk respects PEP 668 and does not force pip to modify an externally managed system Python. Add a virtual environment to inspect and manage its packages separately.

Is it free? Does it send my inventory anywhere?

SweepDesk is free and open source. Scanning runs locally. It does not upload your software inventory or operation logs. Exporting a JSON inventory is your choice.
